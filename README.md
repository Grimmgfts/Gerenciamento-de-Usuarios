# API Connect - Gerenciamento de Usuários

## 📌 Sobre a API
A **API Connect** é uma solução Back-End construída em Node.js e Express desenvolvida para atuar como o ecossistema central de gerenciamento de usuários de uma startup. A aplicação disponibiliza uma interface RESTful leve, eficiente e estruturada sob arquitetura modular (Separation of Concerns), implementando validações rigorosas de dados de entrada e padronização determinística nas respostas JSON.

---

## 🛠️ Tecnologias Utilizadas
- **Node.js** (Ambiente de execução JavaScript no servidor)
- **Express.js** (Framework web para rotas e middlewares REST)
- **Thunder Client / Postman** (Ferramentas de testes de integração e validação HTTP)
- **Git & GitHub** (Controle de versão e hospedagem de código)
